# Wonder World Beta (Ver 1.0.0.beta.1)

Wonder World is a sandbox game that allows you to travel various lands, survive, build, and gather resources to build new tools, equipment, and upgrades.

Since this is a beta build, the game will be buggy and incomplete.

## How to Download

You can download the game installer in either <a href="https://github.com/SuperGamer001/Wonder-World-Beta/releases/tag/v1.0.0-beta.1">the GitHub Release</a> or in the <a href="https://alex.planetkodiak.com/Interlinked-Creations/Library/">Interlinked Game Library</a>.
